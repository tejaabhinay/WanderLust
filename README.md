 
# WanderLust 

Inspired by the global travel movement, WanderLust is a full-stack marketplace where users can list, discover, and book unique stays around the world.

### Features
* **Full Control:** Users can Create, Read, Update, and Delete (CRUD) their listings. 
* **Review System:** Share your experiences with an integrated rating and review tool. 
* **Secure Sessions:** Personalized user experiences with session management. 

### Tech Stack
* **The Engine:** MongoDB, Express, React, Node (MERN) 
* **Styling:** Bootstrap for a polished, professional look.
